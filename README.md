# AIエージェント実務デモ（Agent Workbench）

中小企業・地域金融機関の商談で「AIエージェントが実務を処理する様子」を体感してもらうためのデモアプリです。

- **単一HTML／依存なし／オフライン動作**（外部通信はWebフォントのみ、失敗してもシステムフォントで表示）
- **4業務 × 12業種パターン**を、その場で選んで再生
- 実行中に**人の承認で止まる**設計（選択によってその後の処理が分岐します）

## 収録シナリオ

| 業務 | 業種パターン | 見せどころ |
|---|---|---|
| 見積・受発注エージェント | 金属部品製造 / 食品卸売 / 建設資材商社 | 図面・依頼メールの読取 → 在庫・仕入照会 → 原価積算 → 粗利基準割れで承認待ち |
| AI経営実装診断エージェント | サービス業50名 / 製造業120名 / 小売80名 | 面談メモから業務棚卸し → 同業ベンチマーク照合 → 90日PoC設計 → AI実装カルテ生成 |
| 商談議事録・CRM連携エージェント | BtoBコンサル / 人材サービス / 税理士法人 | 録音の文字起こし → 決定事項・宿題・懸念の仕分け → CRM更新・タスク起票 |
| 現場報告・日報エージェント | 総合建設 / 物流運輸 / 設備工事 | 写真の画像解析（安全指摘の検出）→ 工程照合 → 責任者承認 → 元請提出書式化 |

## 使い方（商談での運用）

1. 相手の業種に一番近いチップを押して開始する
2. 再生速度は `0.5x / 1x / 2x`。説明を挟むときは「一時停止」
3. **承認待ちで止まったら、相手にボタンを押してもらう**（ここが一番効きます）
4. 完了後に表示される時間比較と「次の一歩」で、PoCの話に接続する

## 注意（必ず伝えてください）

- 登場する企業名・数値・帳票はすべて**説明用のサンプル**です。実在の企業・取引とは関係ありません。
- エージェントの処理は**事前設計したシナリオの再生**です。実際のLLM推論は行っていません。
- 削減時間は当該業務の一般的な手作業工数を想定した**参考値**であり、効果を保証するものではありません。

## 更新方法

`index.html` の1ファイルのみです。シナリオ定義は同ファイル内の `SCENARIOS` / `STEPS` にまとまっています。
