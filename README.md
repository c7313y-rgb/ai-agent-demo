# AIエージェント実務デモ（Agent Workbench）

中小企業・地域金融機関の商談で「AIエージェントが実務を処理する様子」を体感してもらうためのデモアプリです。

**公開URL** — https://c7313y-rgb.github.io/ai-agent-demo/

- **単一HTML／依存ライブラリなし／外部通信ゼロ**（Webフォントも読み込みません。閉域網のPCでもそのまま動作）
- **5業務 × 3パターン = 15シナリオ**を、その場で選んで再生
- 実行中に**人の承認で止まる**設計（選択によってその後の処理が分岐します）
- 最後の1本は、あえて**AIが「できない」と判断して止まる**限界ケース

## 収録シナリオ

| 業務 | パターン | 承認ゲート（人が止める場所） |
|---|---|---|
| 見積・受発注エージェント | 金属部品製造 / 食品卸売 / 建設資材商社 | 粗利率が社内基準割れ → 承認 or 単価見直しで分岐 |
| AI経営実装診断エージェント | サービス50名 / 製造120名 / 小売80名 | 優先業務2件の確定 → 2件で進める or ①のみに絞る |
| 商談議事録・CRM連携エージェント | BtoBコンサル / 人材サービス / 税理士法人 | 金額言及あり → 社内版のみ or 先方共有 |
| 現場報告・日報エージェント | 総合建設 / 物流運輸 / 設備工事 | 安全指摘あり → 確定 or 現場差し戻し |
| **AIが「できない」と止まるとき** | 図面が読めない / 前例のない条件 / 音声が聞き取れない | **推測させる or 人にエスカレーション**（推測した場合のコストも試算表示） |

## 商談で使う機能

- **ROI試算** — 件数・時給・所要時間を入力すると、削減時間／削減額（月・年）／人数換算をその場で計算。入力値はブラウザ内だけで処理され送信されません
- **監査証跡** — 「いつ・どのデータを参照し・誰が何を承認したか」を実行ごとに記録。金融機関の審査部門向け
- **ガバナンス説明パネル** — 最終責任者、止まる条件、権限管理、データの置き場所（トップ画面）
- **印刷 / PDF保存** — 成果物（見積書・カルテ・議事録・日報）だけを印刷レイアウトで出力
- **シナリオ直リンク** — `#quote/metal` のようにURLで特定シナリオを直接開ける。営業メールに貼れます
- **再生速度** 0.5x / 1x / 2x と一時停止

## 商談での運用手順

1. 相手の業種に一番近いチップを押して開始する
2. 説明を挟むときは「一時停止」、時間がないときは 2x
3. **承認待ちで止まったら、相手にボタンを押してもらう**（ここが一番効きます）
4. 完了後、ROI試算に**相手が答えた件数と時給**を入れる。ここで体感デモが提案書に変わります
5. 相手が「できないことは？」と聞いてきたら、5本目の「AIが止まるとき」を見せる

## 必ず伝えること

- 登場する企業名・数値・帳票はすべて**架空のサンプル**です。実在の企業・取引とは関係ありません
- エージェントの処理は**事前設計したシナリオの再生**です。実際のLLM推論は行っていません
- 削減時間は当該業務の一般的な手作業工数を想定した**参考値**であり、効果を保証するものではありません
- ROI試算にライセンス費・構築費・教育コストは含まれていません

## 未対応（既知の制約）

- **実LLM接続**は未実装です。APIキーを公開サイトに置けないため、実現にはサーバー側のプロキシ（Cloudflare Workers / Vercel Functions 等）が必要です
- アクセス解析タグは未設置です。必要なら `index.html` の `<head>` に追加してください

## 更新方法

`index.html` の1ファイルのみです。シナリオ定義は同ファイル内の `SCENARIOS` / `STEPS` にまとまっています。
GitHub の「Upload files」で同名アップロードすれば、数十秒で Pages に反映されます。
